02 / Platform Capabilities

Built like a real security operations platform.

The architecture separates ingestion, detections, correlation, investigation, search, graph context, threat intelligence and governed response rather than collapsing everything into one LLM prompt.

01 / INGEST

OCSF-normalized telemetry

Go ingestion services accept connector and webhook data, apply pre-ingest filters, normalize events to OCSF and publish them onto the Kafka event spine.

02 / DETECT

Detection + correlation

A Python fusion layer runs executable rules, promotion logic, correlation, confidence scoring and incident narratives before cases reach the agent layer.

03 / INVESTIGATE

Multi-agent investigation

Detect, Triage, Hunt and Respond divide signal fusion, routing, threat hunting and response planning into explicit roles with recorded tool use.

04 / EXPLAIN

Investigation Ledger

Prompt, response and tool I/O can be replayed or explained through MCP-facing ledger tools, making the investigation path reviewable instead of opaque.

05 / GOVERN

Human-gated response

Response begins as a preview/dry run. Permission tier, separation-of-duties and approval checks gate consequential action execution.

06 / ENRICH

Threat intelligence context

Dedicated services support CISA KEV, TAXII, MISP and OTX feeds, IOC enrichment and threat-actor attribution to add external context to investigations.

06 / MCP Boundary

AI access, typed and traceable.

The TypeScript MCP server exposes 18 tools. Seventeen are read-only; aisoc_run_investigation is the exception because it starts agent work rather than simply reading state.

MCP
SERVER
aisoc_get_alertalert context
aisoc_run_investigationstarts agent run
aisoc_replay_decisionprompt + tool replay
aisoc_preview_actiondry-run response

Small tools beat unrestricted agency.

Investigations are exposed through narrowly scoped capabilities rather than handing an AI model broad direct control. Replay/explain tools make decisions reviewable, while action preview keeps the MCP boundary safe for evaluation.

→ aisoc_list_alerts() ✓ 24 open
→ aisoc_get_alert() ✓ context loaded
→ aisoc_run_investigation() ◷ agent run started
→ aisoc_replay_decision() ✓ trace available
→ aisoc_preview_action() ◷ human review
